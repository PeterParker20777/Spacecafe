SPACE CAFE - QR MENU DEMO

Files: index.html, style.css, script.js, assets/space-cafe-logo.png, assets/menu-fallback.svg
Run: Open folder in VS Code and use Live Server on index.html.

Menu contains 8 sample items per category. Prices are placeholders, not confirmed cafe prices. Photos load from Unsplash when internet is available; if a photo fails, a local placeholder is shown instead of a broken image. Google buttons open the cafe listing; choose Reviews on Google to leave feedback.
